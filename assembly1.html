Asas Seni Bina Komputer

Memahami Set Arahan, Bahasa Mesin & Bahasa Perhimpunan 🚀

Komputer berkomunikasi menggunakan tahap bahasa yang berbeza daripada kod binari berkuasa perkakasan sehingga mnemonic yang mudah difahami oleh manusia.

Definisi 1

Instruction Set (Set Arahan)

Set lengkap **semua arahan asas** (seperti ADD, SUB, MOV) yang diprogramkan secara fizikal ke dalam pemproses (CPU).

Contoh Seni Bina: x86, ARM, MIPS, RISC-V.
Definisi 2

Machine Language (Bahasa Mesin)

Bahasa peringkat paling rendah yang terdiri daripada **digit binari (0 dan 1)**. Ia adalah satu-satunya bahasa yang difahami dan dilaksanakan terus oleh litar perkakasan CPU.

Contoh Kod: 10110000 00000101
Definisi 3

Assembly Language (Bahasa Perhimpunan)

Bahasa pengaturcaraan peringkat rendah yang menggunakan **singkatan simbolik (Mnemonic)** untuk mewakili arahan bahasa mesin supaya mudah dibaca dan ditulis oleh manusia.

Contoh Kod: MOV AL, 5 (Diterjemah oleh Assembler)

Perbandingan & Aliran Penterjemahan

Bagaimana kod arahan bertukar daripada idea manusia kepada litar elektrik CPU

Peringkat Tinggi

x = x + 5;

Mudah difahami manusia, abstrak daripada perkakasan.

Bahasa Perhimpunan

Assembly Language

ADD R1, #5

Menggunakan Mnemonic + Operands. Memerlukan Assembler.

Bahasa Mesin

Machine Language

Satu-satunya kod yang diproses langsung oleh litar logik CPU.

Standard 4.1.2

Format Arahan & Mod Pengalamatan 🧩

Format arahan menentukan struktur bit yang memberitahu pemproses **apa operasi yang perlu dilaksanakan (Opcode)** dan **di mana hendak mendapatkan data (Operand)**. Mod Pengalamatan menerangkan kaedah menentukan *Effective Address (EA)*.

OPCODE (Operation Code)

Pilih medan di atas untuk lihat penjelasan terperinci

**Opcode** menentukan jenis tugas fizikal yang mesti dilakukan oleh CPU. Contoh operasi merangkumi penambahan (ADD), pengurangan (SUB), pemindahan data (MOV), atau lompatan logik (JMP).

Apakah Effective Address (EA)?

**Effective Address (EA)** atau Alamat Efektif ialah alamat fizikal sebenar dalam memori utama (RAM) tempat data operand disimpan dan sedia untuk dicapai oleh CPU.

Mengapa Perlu Mod Pengalamatan?

Memberikan fleksibiliti kepada pengaturcara untuk mengakses pemboleh ubah, tatasusunan (array), struktur data, dan penunjuk (pointers) secara cekap dengan saiz saiz bit arahan yang terhad.

Standard 4.1.3

Jenis-jenis Mod Pengalamatan & Contoh 📚

Pelajari 7 mod pengalamatan utama beserta kaedah penentuan **Effective Address (EA)**, kelebihan, serta contoh kod Perhimpunan sebenar.

1. Serta-merta Sangat Pantas

Immediate Addressing Mode

Nilai operand terkandung **terus di dalam arahan** itu sendiri. Tiada capaian memori diperlukan.

// Format & Contoh
MOV AX, #25
ADD R1, 100
Effective Address (EA): Tiada (Data ada dalam arahan)
Keuntungan: Tiada giliran capaian RAM.
2. Terus 1 Capaian RAM

Direct / Absolute Addressing

Medan operand mengandungi **alamat memori fizikal (EA)** tempat data disimpan.

// Format & Contoh
MOV R1, [1050H]
Effective Address (EA): Address Field (A)
Keuntungan: Mudah dan berkesan untuk pemboleh ubah tetap.
3. Tak Terus 2 Capaian RAM

Indirect Addressing Mode

Medan operand menunjuk ke alamat memori yang menyimpan **alamat sebenar (pointer)** operand.

// Format & Contoh
MOV R1, @[2000H]
Effective Address (EA): Memory[A]
Keuntungan: Sangat fleksibel untuk penunjuk (pointers).
4. Daftar Terus Dalam Daftar CPU

Register Direct Addressing

Operand disimpan terus di dalam **daftar CPU (Register)** yang ditentukan dalam arahan.

// Format & Contoh
ADD R1, R2
Effective Address (EA): Register (R)
Keuntungan: Kelajuan pelaksanaan maksimum!
5. Daftar Tak Terus 1 Capaian RAM

Register Indirect Addressing

Daftar CPU mengandungi **alamat memori fizikal (pointer)** tempat data berada.

// Format & Contoh
MOV R1, [R2]
Effective Address (EA): Content of Register (R)
Keuntungan: Jimat ruang bit arahan.
6. Anjakan / Indeks Pengiraan EA

Displacement / Indexed Mode

Alamat Efektif (EA) dikira dengan **menambah kandungan daftar dengan nilai anjakan (offset)**.

// Format & Contoh
MOV R1, 100[R2]
Effective Address (EA): A + Kandungan Daftar (R)
Keuntungan: Bagus untuk tatasusunan (arrays).
7. Tersirat Operand Otomatik

Implied / Implicit Mode

Operand tidak dinyatakan secara eksplisit kerana ia sudah **sedia maklum secara lalai oleh arahan**.

// Format & Contoh
CLC // Clear Carry Flag
NOP // No Operation
Effective Address (EA): Tersirat dalam pemproses
Keuntungan: Saiz arahan paling kecil (1-byte).
